# Gestionale Ricambi (demo in lavorazione)

Gestionale web per cercare in pochi secondi i ricambi di un'autodemolizione:
per tipo di pezzo, marca, modello, anno, colore, lato (DX/SX), condizione e stato (disponibile/venduto).

> ⚠️ Progetto in lavorazione: l'interfaccia è una demo con dati di prova.

## Cosa c'è già
- Ricerca rapida e filtri per marca
- Segna un pezzo come venduto o rimettilo disponibile
- Inserimento e modifica dei ricambi (tipologie, marche, modelli, colori)
- Interfaccia nei colori dell'azienda (giallo e nero)

## In arrivo
- Backend Node.js + Express e database MySQL
- Login con ruoli, foto dei pezzi, accesso dai telefoni in rete locale
- Backup automatico

## Tecnologie
React, Vite, Node.js, Express, MySQL

## Come provarlo in locale
```
cd frontend
npm install
npm run dev
```
